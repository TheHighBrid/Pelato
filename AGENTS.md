# Pelato development instructions

- Read BLUEPRINT.md before changing scope. Ship usable local audio first.
- Preserve offline-first design, user-owned audio, zero mandatory services and Melato tokens.
- Never introduce paid infrastructure or remote music uploads without owner approval.
- Never bypass DRM or assume permission to publicly broadcast personal music.
- Prefer simple, accessible native browser APIs and no dependencies in v0.1.
- Run npm test and verify playback, persistence, navigation and responsive layout before release.
- Be explicit about unverified browsers, platform constraints and next steps.
